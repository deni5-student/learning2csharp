Visual Studio

Noter om Visual Studio — Microsofts fulde IDE til .NET og C#-udvikling.

💡 Tip: Tryk F5 for at bygge og køre projektet med debugger tilkoblet, eller Ctrl+F5 for at køre uden debugger (hurtigere).

Hvad er Visual Studio?

Visual Studio er en fuld IDE (Integrated Development Environment) fra Microsoft, som er tæt integreret med .NET og C#. Den indeholder bl.a. debugger, designer til brugerflader, NuGet-pakkehåndtering og indbygget Git-understøttelse — alt sammen i ét program.

Solution og Project

I Visual Studio er koden organiseret i en Solution (.sln), som kan indeholde et eller flere Projects (.csproj). Et projekt svarer typisk til én applikation eller ét bibliotek.

Nyttige genveje

  • F5 — Byg og kør projektet med debugger.
  • Ctrl+F5 — Kør projektet uden debugger.
  • Ctrl+Shift+B — Byg hele solutionen.
  • F9 — Sæt eller fjern et breakpoint på den aktuelle linje.
  • F10 / F11 — Step over / step into under debugging.
  • Ctrl+. — Quick Actions — foreslår rettelser og generering af kode.
  • Ctrl+K, Ctrl+D — Formatér hele dokumentet.
  • Ctrl+, — Gå hurtigt til en fil, klasse eller metode.
