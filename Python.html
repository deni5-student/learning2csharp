Python

En introduktion til Python — et af de mest populære programmeringssprog, kendt for sin enkle og letlæselige syntaks.

💡 Tip: Python bruger indrykning (mellemrum/tab) i stedet for krøllede parenteser { } til at afgrænse kodeblokke — det er en del af sprogets syntaks, ikke bare formatering.

Hvad er Python?

Python er et fortolket (interpreted) og dynamisk typet sprog, der bruges bredt inden for alt fra webudvikling og automatisering til dataanalyse og maskinlæring. Det er ofte et godt sprog at starte med, fordi koden minder om almindeligt engelsk og kræver mindre "boilerplate" end sprog som C#.

Eksempel på Python kode

navn = "Verden"
alder = 20

print(f"Hej {navn}, du er {alder} år gammel!")

if alder >= 18:
    print("Du er myndig.")
else:
    print("Du er ikke myndig endnu.")

for i in range(3):
    print(f"Runde {i + 1}")

Grundlæggende koncepter

  • print() — Skriver tekst eller værdier ud i konsollen.
  • variabel = værdi — Opretter en variabel; ingen typedeklaration nødvendig.
  • input() — Læser input fra brugeren i konsollen.
  • if / elif / else — Betingelser, der styrer programmets flow.
  • for og while — Løkker til at gentage kode.
  • list, dict, tuple — Indbyggede datastrukturer til at gemme flere værdier.
  • def — Bruges til at definere en funktion.
  • Indrykning — Bruges i stedet for { } til at markere kodeblokke.
  • import — Henter funktionalitet fra andre moduler og biblioteker.
  • # kommentar — Alt efter # på en linje ignoreres af Python.
