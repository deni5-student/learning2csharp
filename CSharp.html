C# Learning

Grundlæggende noter om C# — udgangspunktet for hele denne wiki. Siden bliver udvidet løbende med noter fra undervisningen.

💡 Tip: C# er stærkt og statisk typet — det betyder, at hver variabel har en fast type, som compileren tjekker allerede inden programmet køres.

Hvad er C#?

C# (udtales "C sharp") er et objektorienteret programmeringssprog udviklet af Microsoft. Det køres på .NET-platformen og bruges bredt til alt fra desktop-programmer og webudvikling til spiludvikling (fx i Unity).

Grundlæggende syntaks

using System;

class Program
{
    static void Main()
    {
        string navn = "Verden";
        int alder = 20;

        Console.WriteLine($"Hej {navn}, du er {alder} år gammel!");

        if (alder >= 18)
        {
            Console.WriteLine("Du er myndig.");
        }
        else
        {
            Console.WriteLine("Du er ikke myndig endnu.");
        }

        for (int i = 0; i < 3; i++)
        {
            Console.WriteLine($"Runde {i + 1}");
        }
    }
}

Objektorienteret programmering (OOP)

C# er bygget op omkring OOP-principper som klasser, objekter, indkapsling og arv. En klasse er en skabelon, man kan lave objekter (instanser) ud fra.

class Person
{
    public string Navn;
    public int Alder;

    public Person(string navn, int alder)
    {
        Navn = navn;
        Alder = alder;
    }

    public void SigHej()
    {
        Console.WriteLine($"Hej, jeg hedder {Navn}!");
    }
}

// Brug af klassen:
Person person1 = new Person("Dennis", 20);
person1.SigHej();

Grundlæggende koncepter

  • class — Definerer en klasse (en skabelon for objekter).
  • static void Main() — Programmets indgangspunkt, hvor koden starter med at køre.
  • Console.WriteLine() — Skriver tekst ud i konsollen.
  • int, string, bool, double — Nogle af de mest almindelige datatyper.
  • if / else — Betingelser, der styrer programmets flow.
  • for, while, foreach — Løkker til at gentage kode.
  • public / private — Bestemmer hvem der kan tilgå en variabel eller metode (indkapsling).
  • Konstruktør — En speciel metode, der kører, når et objekt oprettes med new.
  • Arv (inheritance) — En klasse kan arve egenskaber og metoder fra en anden klasse.
  • // kommentar — Alt efter // på en linje ignoreres af compileren.
