Fagord

Et glossar over de vigtigste C#-fagudtryk — på dansk og engelsk. Fokus er ikke kun på, hvad en kodelinje gør, men på hvad du faktisk har gjort, når du skriver den. Det er dét, der skal kunne siges højt til en mundtlig eksamen.

💡 Tip: Øv dig i at sige forklaringen højt, ikke kun læse den. Det er overgangen fra at "vide" til at "kunne forklare i realtid", der driller mest til eksamen.

Klasse

(Class)

En klasse er en skabelon — en beskrivelse af, hvordan noget skal se ud og opføre sig, men den er ikke selve tingen. Man kan sammenligne det med en tegning af et hus: tegningen er ikke huset, men bestemmer, hvordan ethvert hus bygget efter den kommer til at se ud.

Når du skriver class Person { ... }, har du defineret en ny type i dit program — en opskrift på, hvilke data (fx navn, alder) og hvilken adfærd (fx metoder) et objekt af den type skal have.

class Person
{
    public string Navn;
    public int Alder;
}

Objekt / Instans

(Object / Instance)

Hvis en klasse er tegningen af huset, er et objekt selve det byggede hus. Et objekt er en konkret "ting" i hukommelsen, lavet ud fra en klasses skabelon. Man kan lave mange forskellige objekter (huse) ud fra samme klasse (tegning).

Ordet instans bruges tit i stedet for "objekt" — de betyder stort set det samme: én konkret udgave af en klasse.

Person person1 = new Person();
Person person2 = new Person();
// person1 og person2 er to forskellige objekter (instanser)
// af samme klasse Person

Konstruktør

(Constructor)

En konstruktør er en speciel metode, der bliver kaldt automatisk, i det øjeblik et nyt objekt oprettes med nøgleordet new. Dens job er at sætte objektet klar til brug — fx give det en startværdi.

Hvad sker der egentlig, når man skriver Person person1 = new Person();? Det er ikke bare "man opretter et objekt" — der sker tre ting på én gang:

  • Person (foran =) — Man definerer en variabel, som får typen Person.
  • new Person() — Man beder .NET om at afsætte plads i hukommelsen og oprette et nyt objekt af typen Person, ved at kalde dens konstruktør.
  • = — Man gemmer en reference til det nyoprettede objekt i variablen person1 — variablen indeholder altså ikke selve objektet, men en "adresse" hen til det i hukommelsen.
class Person
{
    public string Navn;

    // Dette er konstruktøren — kører automatisk ved "new"
    public Person(string navn)
    {
        Navn = navn;
    }
}

// Kalder konstruktøren og sender "Dennis" med som argument:
Person person1 = new Person("Dennis");

Array

(Array)

Et array er en samling af værdier af samme type, gemt i en fast, nummereret rækkefølge. Størrelsen er låst fast, når arrayet oprettes — man kan ikke bagefter tilføje eller fjerne pladser.

Hvert element har et index (en position), der starter ved 0 — ikke 1. Det første element har altså index 0, det andet index 1, og så videre.

int[] tal = { 10, 20, 30 };
// tal[0] er 10, tal[1] er 20, tal[2] er 30

Metode

(Method)

En metode er en navngivet blok af kode, som udfører en bestemt opgave, og som kan kaldes (bruges) igen og igen uden at skulle skrives forfra hver gang. Man kan tænke på det som en handling, et objekt kan udføre.

class Person
{
    public string Navn;

    public void SigHej()
    {
        Console.WriteLine($"Hej, jeg hedder {Navn}!");
    }
}

Person person1 = new Person();
person1.SigHej(); // kalder metoden på objektet

Variabel

(Variable)

En variabel er et navngivet stykke plads i hukommelsen, som gemmer en værdi af en bestemt type. I C# skal variablens type angives (eller udledes med var), og typen kan ikke ændres bagefter — det er det, der menes med at C# er stærkt og statisk typet.

int alder = 20;      // en int-variabel
string navn = "Dennis"; // en string-variabel
var by = "Odense";   // compileren udleder selv, at "by" er en string

Indkapsling

(Encapsulation)

Indkapsling betyder at skjule de indre detaljer af en klasse, og kun vise det udadtil, som andre dele af programmet faktisk har brug for. Det gøres med adgangsmodifikatorerne public (kan tilgås udefra) og private (kan kun tilgås inde i klassen selv).

Formålet er at beskytte data mod at blive ændret forkert udefra — man styrer, hvordan objektets data kan bruges, i stedet for at give fri adgang til alt.

class Konto
{
    private double saldo; // kan IKKE tilgås udefra

    public void Indsæt(double beløb)
    {
        saldo += beløb; // kun klassen selv kan ændre saldo direkte
    }
}

Arv

(Inheritance)

Arv betyder, at en klasse kan overtage egenskaber og metoder fra en anden klasse, i stedet for at skulle skrive det hele forfra. Den klasse, der arver, kaldes en subklasse; den man arver fra, kaldes superklasse (eller basisklasse).

class Dyr
{
    public void LavLyd()
    {
        Console.WriteLine("Dyret laver en lyd.");
    }
}

// Hund arver fra Dyr, og får dermed adgang til LavLyd()
class Hund : Dyr
{
}

Hund minHund = new Hund();
minHund.LavLyd(); // virker, selvom metoden ikke står i Hund-klassen

Løkke

(Loop)

En løkke er en kodeblok, der gentages, indtil en bestemt betingelse ikke længere er sand. Bruges til at undgå at skrive den samme kode mange gange manuelt.

  • for — Bruges når man kender antallet af gentagelser på forhånd, og/eller har brug for et index.
  • foreach — Bruges til at gennemløbe alle elementer i en samling (fx et array), uden at skulle styre index selv.
  • while — Bruges når gentagelsen skal fortsætte, indtil en betingelse bliver falsk — uden at man nødvendigvis ved hvor mange gange på forhånd.

Betingelse

(Conditional statement)

En betingelse styrer, hvilken kode der bliver kørt, afhængigt af om et udsagn er sandt (true) eller falsk (false). Det gør programmet i stand til at "træffe beslutninger" baseret på data.

int alder = 20;

if (alder >= 18)
{
    Console.WriteLine("Du er myndig.");
}
else
{
    Console.WriteLine("Du er ikke myndig endnu.");
}
