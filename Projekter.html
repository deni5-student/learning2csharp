Gæt Et Tal

Et lille konsolspil: computeren vælger et tilfældigt tal mellem 1 og 100, og du skal gætte det med så få forsøg som muligt. Efter hvert gæt fortæller programmet, om tallet skal være højere eller lavere.

Kildekode (C#)

public class GætEtTal
{
    public void Start()
    {
        bool kører = true;
        Random rnd = new Random();
        int hemmeligtTal = rnd.Next(1, 101);
        int forsøg = 0;

        while (kører)
        {
            Console.Clear();
            Console.WriteLine("Velkommen til gæt et tal spillet");
            Console.WriteLine("Du skal prøve og gætte et tal mellem 1 & 100");
            Console.WriteLine("Antal forsøg: " + forsøg);
            Console.WriteLine("Skriv det vil gætte på:");
            string input = Console.ReadLine();

            int gæt = int.Parse(input);

            if (gæt == hemmeligtTal)
            {
                Console.WriteLine("du gættede rigtigt!");
                forsøg++;
                kører = false;
                Console.ReadKey();
            }
            else if (gæt < hemmeligtTal)
            {
                Console.WriteLine("Tallet du skal gætte er højere");
                forsøg++;
                Console.ReadKey();
            }
            else if (gæt > hemmeligtTal)
            {
                Console.WriteLine("Tallet du skal gætte er lavere");
                forsøg++;
                Console.ReadKey();
            }
            else if (input == "q")
            {
                Console.WriteLine("Tak for spillet");
                break;
            }
            else
            {
                Console.WriteLine("forkert input");
                Console.ReadKey();
            }
        }
    }
}
💡 Bemærk: q-grenen i den rigtige C#-kode rammes faktisk aldrig — int.Parse(input) kaster en exception, før koden når frem til at tjekke for "q". Terminal-simulationen herunder retter denne bug, så 'q' rent faktisk afslutter spillet.
